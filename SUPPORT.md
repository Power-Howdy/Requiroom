# Support

## Questions and help

- **Bugs and features** — use GitHub Issues on this repository
- **Contributing** — [CONTRIBUTING.md](CONTRIBUTING.md)
- **Security** — [SECURITY.md](SECURITY.md) (private reports only)

## What maintainers can help with

- Reproducing crashes or desktop shell bugs
- Clarifying architecture and contribution process
- Accepting well-scoped pull requests

## What we generally cannot do

- Debug every third-party website through the proxy (compatibility varies)
- Provide managed hosting or SLA for public demo deployments
- Store or recover your API keys (they live only in your browser’s IndexedDB)

## Self-hosting

See the README **Deploy** section and [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
You are responsible for security hardening and acceptable-use policies on any
public instance that exposes `/api/proxy` or `/api/llm`.
